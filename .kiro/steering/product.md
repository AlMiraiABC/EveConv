# Product Overview

EveConv is a conversational AI system built with a modular architecture focusing on knowledge management, memory, and data storage capabilities.

## Core Components

- **Knowledge Management**: File extraction and knowledge processing
- **Memory System**: Conversational memory and context management  
- **Storage Layer**: Multi-modal storage including vector, graph, and relational databases
- **LLM Layer**: Large Language Model integration
- **API Layer**: RESTful API for system interaction

## Domain Focus

The system appears designed for conversational AI applications that require:
- Document processing and knowledge extraction
- Persistent conversation memory
- Multi-modal data storage and retrieval
- Scalable API access patterns
